Global agent instructions. Canonical file: ~/.agents/AGENTS.md — edit there, then re-paste here. Conventions: handoff documents go in ~/handoffs/<slug>.md, not the workspace and not $TMPDIR. These skills cannot start themselves, so suggest them rather than waiting to be asked: blast-radius before a migration, legacy removal or any wide refactor; grill-with-docs before designing a feature or module; handoff when ending a session with work unfinished; wait-what when an explanation did not land; comment-sweep when a diff has grown noisy comments or suppressions; improve-codebase-architecture when deciding where a module boundary goes; pick-ui-library when choosing a frontend library; prototype when exploring what a piece of UI should look like; review-animations when reviewing animation or motion code; interface-review when reviewing a change's interface quality rather than its correctness; break when checking whether one component survives real content; explain-interface when asking how an interface you can see was built. Everything else in ~/.agents/skills/ fires on its own when it matches.
