# Glossary

## Source answer

The assistant message selected for re-expression. By default, this is the most recent substantive assistant answer before the user's request.

## Focus

Optional user guidance that identifies the part of the source answer that was difficult to understand.

## Rewrite

A clearer expression of the source answer that preserves its meaning, evidence, uncertainty and decision-relevant detail.

## Fidelity

The rewrite adds no factual claim or recommendation absent from the source answer and omits no decision-relevant fact, condition, warning or uncertainty.
